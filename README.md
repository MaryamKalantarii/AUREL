# AUREL — Objects of Light

A cinematic luxury jewelry ecommerce frontend starter built with Next.js, TypeScript, GSAP, Lenis, Zustand and React Three Fiber.

## Stack

- Next.js App Router
- React + TypeScript
- GSAP + ScrollTrigger
- Lenis smooth scrolling
- Zustand cart state
- Three.js / React Three Fiber foundation
- Lucide icons

## Run

```bash
npm install
npm run dev
```

Then open http://localhost:3000
